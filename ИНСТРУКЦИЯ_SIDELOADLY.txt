================================================================================
📱 SIDELOADLY MESSENGER ДЛЯ iOS — ПОЛНОЕ РУКОВОДСТВО ПО СБОРКЕ И УСТАНОВКЕ
================================================================================

Создан полноценный современный мессенджер на чистом нативном SwiftUI (iOS 16, 17, 18+).

✨ ЧТО РЕАЛИЗОВАНО В ОФОРМЛЕНИИ И ФУНКЦИОНАЛЕ:
--------------------------------------------------------------------------------
• Дизайн Liquid Glass / iOS 18:
  - Размытие материалов (.ultraThinMaterial), плавные spring-анимации.
  - Поддержка Светлой и Тёмной темы с динамическим переключением.
  - Анимированные пузыри сообщений с градиентами (Telegram/iMessage стиль).
  - Тактильный отклик (Haptic Feedback) на каждое действие.
• Интерактивные чаты:
  - Двойные галочки статуса доставки и прочтения сообщений.
  - Индикатор набора текста ("печатает...") с анимированными точками.
  - Голосовые сообщения с кликабельным плеером и звуковой волной.
  - Реакции на сообщения (❤️, 👍, 🔥, 😂, 😮, 😢, 🎉) по долгому нажатию.
  - Меню прикрепления фото, камеры, геопозиции и файлов.
  - Встроенный интерактивный автоответчик / бот, чтобы приложение оживало сразу при запуске.
• Лента историй и активных контактов вверху списка чатов.
• Экран настроек: профиль, аватарки, очистка кэша, статус 7-дневного сертификата Sideloadly,
  а также возможность подключить свой реальный WebSocket сервер (wss://).

================================================================================
🚀 ШАГ 1: КАК ПОЛУЧИТЬ ГОТОВЫЙ .IPA БЕЗ MAC (ЧЕРЕЗ GITHUB ACTIONS ЗА 2 МИНУТЫ)
================================================================================
iOS требует Mach-O arm64 бинарник, который компилируется Apple Clang.
В проекте уже настроен автоматический CI/CD робот `.github/workflows/build-ipa.yml`,
который использует бесплатный облачный Mac от GitHub:

1. Зайдите на https://github.com и создайте новый приватный или публичный репозиторий (например, `my-ios-messenger`).
2. Загрузите в него содержимое папки `ios-messenger`:
   - Либо просто перетащите файлы через кнопку "Add file" -> "Upload files" в браузере.
   - Либо через консоль:
       git init
       git add .
       git commit -m "Initial commit"
       git branch -M main
       git remote add origin https://github.com/ВАШ_ЛОГИН/my-ios-messenger.git
       git push -u origin main
3. Перейдите во вкладку **Actions** в репозитории.
4. Вы увидите запущенный процесс "Build iOS IPA for Sideloadly".
5. Через ~2 минуты сборка завершится зеленой галочкой.
6. Нажмите на завершенный запуск, промотайте вниз до раздела **Artifacts** и скачайте `Sideloadly-Messenger-IPA.zip`.
7. Распакуйте архив — внутри будет лежать готовый `Messenger.ipa`!

================================================================================
📲 ШАГ 2: УСТАНОВКА ЧЕРЕЗ SIDELOADLY НА IPHONE
================================================================================
1. Скачайте и запустите программу Sideloadly на компьютере (https://sideloadly.io/).
2. Подключите ваш iPhone к компьютеру через USB-кабель (если телефон спросит — выберите "Доверять этому компьютеру").
3. В окне Sideloadly:
   - В поле **iDevice** должен определиться ваш iPhone.
   - Перетащите файл `Messenger.ipa` в левую верхнюю иконку IPA в окне Sideloadly.
   - В поле **Apple ID** введите адрес вашей почты Apple ID (пароль запрашивается для подписи бесплатным 7-дневным сертификатом разработчика Apple).
4. Нажмите кнопку **Start**.
5. Дождитесь надписи "Done!". Приложение появится на домашнем экране iPhone.

================================================================================
🔑 ШАГ 3: ПЕРВЫЙ ЗАПУСК НА IPHONE (ДОВЕРИЕ СЕРТИФИКАТУ)
================================================================================
При первой установке любого приложения через Sideloadly iOS блокирует запуск до подтверждения доверия:
1. Откройте на iPhone: **Настройки -> Основные -> VPN и управление устройством** (или Управление профилями).
2. В разделе "ПО разработчика" нажмите на ваш Apple ID.
3. Нажмите кнопку **"Доверять [Ваш Apple ID]"**.
4. (Для iOS 16, 17, 18+):
   Если появится уведомление о режиме разработчика:
   Зайдите в **Настройки -> Конфиденциальность и безопасность -> Режим разработчика** -> включите тумблер и перезагрузите iPhone по запросу.

🎉 ГОТОВО! Теперь открывайте Messenger — всё настроено, выглядит потрясающе и летает на вашем iPhone!
